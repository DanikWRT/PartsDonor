# PartsDonor

B2B-маркетплейс б/у (донорских) запчастей смартфонов между мастерскими.

- **Проблема:** у мастерских залеживаются запчасти, Авито неудобен для B2B (комиссии + минимум на дешёвых деталях, 0 бесплатных размещений, нет B2B-инструментов).
- **Решение:** нишевая площадка «мастерская → мастерская» с интерактивной развёрткой телефона (клик по компоненту), историей происхождения детали, безопасной сделкой.
- **Рынок:** ниша подтверждена как свободная (см. `docs/strategy.md`).

## Структура

```
docs/strategy.md            # консолидированный ресерч + стратегия (рынок, мотивация, логистика, стек)
docs/market-scope-report.md # исходный ресерч рынка
docker-compose.inventree.yml # InvenTree (склад запчастей) локально
```

## InvenTree (локальный склад запчастей)

Разворачивается в Docker. InvenTree служит **headless-инвентарём** (Part, StockItem, фото, статусы, кастомные поля, BOM, REST API); поверх него пишется наш B2B-маркетплейс-слой.

```bash
# поднять (docker доступен через группу или sg docker)
docker compose -f docker-compose.inventree.yml up -d

# первая инициализация БД (если пустая/сброшенная):
docker compose -f docker-compose.inventree.yml run --rm inventree-server invoke update

# админ создаётся автоматически из env INVENTREE_ADMIN_*
#   логин: admin / admin123 (admin@partsdonor.local)
```

- Панель: **http://127.0.0.1:8000**
- API: `http://127.0.0.1:8000/api/`
- Django admin: `http://127.0.0.1:8000/admin/`
- Данные лежат в `./data/` (в git не коммитится).

### Подводный камень (разборка)
Официальный образ `inventree/inventree:stable` **не применяет миграции при старте сам** — он детектит `INVE-W8: Database Migrations required` и **сознательно завершает процесс**. Миграции надо запускать явно: `invoke update` (отдельным `docker compose run`). Если миграция ломается на `column ... already exists` — БД частично мигрировала; при нулевых данных чище сбросить `./data/db` и повторить.

## Стек-решение (референсы)

- Инвентарь: **InvenTree (MIT)** — headless backend.
- UI развёртки: **@cloudimage/hotspot (MIT)** — вьювер; **react-image-hotspot-viewer (MIT)** — редактор схемы.
- Оплата: **ЮKassa «Безопасная сделка»** (эскроу, от 0,4%).
- Доставка: **СДЭК API** + Почта (резерв).
