# PartsDonor UX-3 spec: мобильная «липкая» CTA-кнопка

## Цель (R2)
70% сессий PartsDonor — со смартфонов (просмотр), 30% покупка.
На мобильном (<768px) в карточке детали — фиксированная внизу «липкая»
(sticky) кнопка покупки, закреплённая при скролле. На десктопе — НЕТ
sticky-бара (кнопки остаются в обычном месте в карточке).

## Acceptance
1. На мобильной вью (ширина < 768px) карточки детали видна sticky-кнопка
   CTA, закреплённая внизу вьюпорта при скролле.
2. На десктопе (>= 768px) sticky-бар отсутствует (кнопки покупки — в обычном
   месте внутри карточки, как сейчас).
3. Sticky-бар смотрит хорошо: полноразмерный, безопасная нижняя отступка
   (safe-area / env(safe-area-inset-bottom)), не перекрывает контент
   (добавить padding-bottom к странице на мобильном), не «мигает» при загрузке.
4. Действие sticky-кнопки = первичное CTA карточки:
   - если есть активное предложение  -> «Купить со сделкой» (переход /deal)
   - если продано -> «Сообщить, когда появится» (подписка, та же логика)
   - если готов 1-клик -> «⚡ Купить в 1 клик»
   - если listing -> «В корзину»
   Реализовать разумно: как минимум primary дейсствие (Купить со сделкой /
   подписка / в корзину). Не дублировать несущественные.
5. Никаких регрессий: npm build проходит (exit 0), прочая вёрстка не ломается.

## Файлы
- frontend/src/pages/PartDetail.jsx  (добавить sticky-бар + логика действия)
- frontend/src/styles.css            (стили для .pd-sticky-cta, медиа-запросы)

## Реализация (подсказка)
- В PartDetail рендерить блок-бар только когда есть действие:
  ```
  <div className="pd-sticky-cta">
     {noActiveOffers ? подписка-кнопка
        : <Link to="/deal" className="pd-cta pd-cta-bar">Купить со сделкой</Link>}
  </div>
  ```
  (можно добавить и «Купить в 1 клик»/«В корзину» как вторичную, но не обязательно).
- CSS: .pd-sticky-cta { position: fixed; left:0; right:0; bottom:0; z-index:50;
  display:none; } показывать только @media (max-width: 767px){ }
  с padding, background, тенью, safe-area inset. Добавить padding-bottom к
  .pd-detail на мобильном, чтобы контент не перекрывался.
- Десктоп: display:none (по умолчанию).

## Верификация
- npm run build (или vite build) -> exit 0.
- py/проверки не требуются (frontend-only). Можно пройти по DOM в браузере
  на мобильной ширине: sticky-бар виден; на десктопе отсутствует.
