# PartsDonor UX-4 spec: 2D-чертёж для плоских деталей + hotspot

## Цель (R2)
Сейчас вся F7-развёртка (DonorView.jsx) рисует детали донора как псевдо-3D
«слои взрыва» (exploded), независимо от того, плоская деталь или объёмная.
Задание: сделать НЕ единый формат — различать тип детали и показывать:
- для ПЛОСКИХ деталей (экраны/дисплеи, стекло, корпус-пластины, крышки, панели) —
  плоский 2D-ЧЕРТЁЖ (вид сверху: контур + размерные линии + отверстия/пазы)
  с HOTSPOT — кликабельной зоной, клик по которой открывает панель детали;
- для ОБЪЁМНЫХ деталей (платы, аккумуляторы, камеры, разъёмы, моторы) —
  существующая 3D/разнесённая развёртка (layers как сейчас).

ACCEPTANCE: у плоских деталей показывается 2D-схема + hotspot, у объёмных —
3D-развёртка; клик по зоне открывает панель (DetailPanel, без изменений).

## Файлы (frontend-only)
- frontend/src/pages/DonorView.jsx  — детекция типа детали + 2D-чертёж/hotspot
- frontend/src/styles.css            — стили для 2D-чертежа и hotspot
НЕ трогать backend/* и другие страницы. Без регрессий.

## Дизайн-решения (зафиксированы, следуй им)

### 1) Детекция типа детали (фронт-эвристика, менять нормализованный слот НЕ надо)
В DonorView после normalizeSlot (как сейчас) добавь функцию `isFlat(slotKey, rawName)`:
- FLAT (2D-чертёж + hotspot), если slotKey/нормализованное имя содержит:
  display, дисплей, экран, screen,
  backcover, корпус (когда это пластина/стекло задней крышки), стекл, glass,
  крышк, задн, панел, пластин, фронт/фронтальное стекло.
- ВСЁ остальное (board, battery, camera, разъёмы, моторы, и любой неизвестный слот)
  считается ОБЪЁМНЫМ -> 3D-развёртка (текущее поведение).
Для простоты можно расширить существующий normalizeSlot, вернув из него
доп. признак, ЛИБО отдельной функцией пройти по c.slot и c.title.
ВАЖНО: camera, board, battery остаются ОБЪЁМНЫМИ (камера — объёмный модуль по ТЗ).
backcover/display становятся ПЛОСКИМИ.

### 2) Рендер F7
В компоненте развёртки (ExplodedScheme) каждую деталь рисуй по её типу:
- FLAT -> новый компонент <FlatDrawing comp={c}/> внутри hotspot-кнопки
  .pd-flat-hotspot (clickable зона) + подпись .pd-layer-tag (переиспользуй
  существующие классы статуса: in/sold/grey) + точка .pd-dot.
- VOLUMETRIC -> текущий <SlotLayer .../> как есть (3D-слой), НИЧЕГО не менять.

Оба типа: клик по зоне/слою -> onSelect(c) -> открывает существующую DetailPanel.
onSelect/selected/DetailPanel/статус-логику НЕ трогать.

### 3) 2D-чертёж FlatDrawing (SVG, вид сверху, «технический чертёж»)
Контур формы детали (прямоугольник со скруглениями под экран/стекло, или
прямоугольная пластина корпуса), отрисованный как ЧЁРТЁЖ, а НЕ объём:
- тонкий контур (2 слоя: внешний контур + внутренний, штриховой/сплошной),
- размерные линии со стрелками (dimension lines) по длине и ширине,
- метки отверстий/пазов (маленькие кружки/пазы на контуре) для «сборочных» зон,
- небольшой уголок «технологии» (крест/центровые оси пунктиром),
- подпись размера (например «6.1″» для display или габариты mm для пластины).
Построение: SVG через JSX, используй вспомогательную <FlatPartDrawing slot=...>.
Храни однобокую палитру/стили в стилях .pd-flat-*.
Визуально должно отличаться от 3D-слоёв (плоское, чертёжное).

### 4) CSS
Добавь секцию .pd-flat-* (hotspot кнопка, чертёжная SVG, размер, размерные
линии, подписи, состояния in/sold/grey, hover + selected подсветка как у
.pd-layer-btn). Переиспользуй уже существующие токены стилей F7 (не ломай).
Адаптив: на мобильном не ломать раскладку (те же правила q-запросов, что и для
.pd-layer-btn).

## Верификация (ОБЯЗАТЕЛЬНО, обе части)
1. `cd frontend && npm run build` -> exit 0 (поправь пока не будет 0).
2. LIVE на 127.0.0.1:5173 (backend 127.0.0.1:8001 жив; vite дев-сервер жив;
   /api проксирует на backend). Открой развёртку донора (маршрут
   /donor/Apple/iPhone 13 Pro или любой доступный). Через headless-браузер
   (playwright chromium уже стоит) проверь:
   a) деталь-экран (display) и корпус/стекло (backcover) рендерятся как 2D-чертёж
      + кликабельная зона .pd-flat-hotspot;
   b) камера (camera), плата (board), аккумулятор (battery) рендерятся как
      3D-слои (существующие .pd-layer-btn/.pd-layer-svg), НЕ как 2D;
   c) клик по 2D-горячей зоне (display) открывает DetailPanel (.pd-f7-panel),
      показывает title/цену/статус;
   d) клик по 3D-слою (камера) тоже открывает DetailPanel;
   e) мобильная ширина (400px) и десктоп (1280px) — без горизонтального
      переполнения, чертёж и панель не ломаются.
   Запиши результат в backend/_ux4_verify.log (текст: PASS/FAIL + метрики DOM,
   как в прошлых UX-верификациях). Сделай скриншоты pd-ux4-flat2d-desktop.png,
   pd-ux4-vol3d-desktop.png, pd-ux4-flat2d-mobile.png в /home/aifactory/PartsDonor/.
