## 1. Есть ли такие ресурсы уже? — Ключевой вывод: ниша свободна

**Полноценного маркетплейса «мастерская ↔ мастерская» для б/у (донорских) запчастей нет ни в России, ни на Западе, ни в Азии.** Все реальные операторы закрывают задачу лишь частично, тремя типами:

| Тип | Примеры | Чем НЕ является PartsDonor |
|---|---|---|
| B2B-маркетплейсы **целых** б/у устройств (для разборки) | Callisto, Gob2bmobile, BidAllies, RecirQ, Cellbie (UK/US) | продают **лотами целые аппараты**, не детали |
| Оптовые магазины запчастей с категорией «донор/снятая деталь» | **MOSBRO** (платы-донор iPhone), **ORIG-SERVICE**, **WEPRO**, **iParts4U** (UK "Genuine Reclaimed"), MobileSentrix | это **склады-продавцы**, а не площадка между мастерскими |
| Китайские площадки / опт | Alibaba (donor boards от $14), AliExpress | B2B из Китая, без истории происхождения |

**В РФ ближайшие аналоги:**
- **SWAPE** (swape.ru) — единственный настоящий P2P-маркетплейс б/у деталей, но застрял на **28 объявлениях / 4 продавцов / один город (Киров)**. Комиссия ~20% со сделки, безопасная сделка через ПВЗ. Ранний прототип, подтверждающий модель, а не лидер.
- **POISKZIP** (poiskzip.ru) — B2B-агрегатор для мастерских, но тянет **новые** запчасти от поставщиков, не P2P б/у.
- **EKSION** — продаёт доноры-смартфоны мастерским (one-to-many, не P2P).
- **Цифрос** (Липецк) — магазин с разбором, полный цикл «приём→разбор→фото→карточка», но это отдельный склад.

**Главный факт:** реальный рынок б/у между мастерскими живёт в **тысячах Telegram-каналов** (@mobiplusservice, @spareparts92 и т.д.) — фрагментированно, вручную, без каталога, гарантий и безопасной сделки. Это и твой источник доказанного спроса, и главный конкурент за привычку.

**По интерактивной схеме телефона (ключевой фит PartsDonor):** механика «клик по развёртке → выбор компонента» **доказана и коммерциализирована** — SaaS-инструменты **Uncap Diagrams** (Shopify, Platinum Partner, fitment-check), **Konfigr** (hotspots → корзина), **Documoto** (EPC-каталоги OEM), примеры у **Samsung Parts** (Exploded View Search) и **Apple** (Internal View + orderable parts). Но **именно для донорских б/у запчастей смартфонов с историей происхождения готового решения нет** — есть шаблоны, которые PartsDonor адаптирует. Это уникальное окно: никто не соединил «клик по схеме» с «б/у деталью с историей».

**Вывод по вопросу 1:** ниша подтверждена как **вакантная**. Прямого конкурента с той же моделью (B2B + донорская деталь + история происхождения + клик по схеме) нет. Риск — не другой маркетплейс, а асимметрия «магазин-склад с готовым ассортиментом» (MOSBRO, iParts4U) и китайский опт по цене.

## 2. Как замотивировать мастерские выкладывать (чтобы было не в лом)

Это классическая **проблема холодного старта на стороне предложения** (chicken-and-egg). Ресерч дал перечень того, что **доказанно работает** в маркетплейсах с мелкими продавцами (eBay, Etsy, Faire, Tradeloop, profit.deals):

### Приоритет 1 — Убить трение выкладки (самая дешёвая и проверенная механика, +20% удержания)
Мастеру лом описывать и фотографировать 10-30 деталей. Поэтому:
- **Фото → автоописание/автоопределение запчасти.** eBay уже делает это AI-инструментом: загрузил фото — получил готовый черновик листинга (категории, тайтлы, атрибуты). Для PartsDonor это главная фича: мастер фотографирует экран/плату, платформа сама определяет модель и тип.
- **«Продай похожее» (Sell Similar)** — клон существующего листинга под шаблон (один тип экрана в разных состояниях). Это база для массовой выкладки однотипных запчастей.
- **Массовое добавление / импорт из Excel/CSV** — критично для мастерской, у которой уже есть свой учёт (таблица со складом). eBay: Mass Edit, CSV feed.
- **Скан штрихкода / фото-распознавание** модели.

**Главное:** трение должно уйти с «не хочу» почти до нуля. «Сфотографировал — оно само описалось».

### Приоритет 2 — «Бесплатно выложить, комиссия только с продажи»
- eBay: 250 бесплатных листингов/мес + комиссия только после продажи. Mercari/Vinted вообще убрали комиссию с продавца.
- **Предупреждение (документировано):** не делать частых скидочных промо на комиссию — они приучают продавцов придерживать инвентарь и выставлять только в период акций.
- Урок Etsy: повышение комиссии (5%→6.5% + $0.20 + плата за магазин) вызвало **исход продавцов**. Не вводить плату «за выставку без продажи».

### Приоритет 3 — Якорный выкуп/оптовик (самое мощное для PartsDonor, но дорогое)
Мастерская часто не хочет продавать «мёртвую» плату по частям — ей проще **сдать партию целиком и получить деньги сразу**. Работающая механика:
- **Кнопка «Продать сразу площадке/оптовику»** — мастерская одним действием отдаёт неликвид якорному скупщику, который разберёт и продаст сам. Это обнуляет трение для самого ленивого поставщика.
- **Минимальная гарантия выкупа партии** (модель «minimum earnings guarantee» из райдшеринга).
- **Аура активности** (NFX): площадка сама должна показать «у нас уже есть предложение», чтобы победить страх «пустого каталога».

### Приоритет 4 — Уровни поставщика С денежной ценностью
Модель profit.deals: статус привязан к объёму → ниже комиссия + быстрее выплаты + топ-выдача:
- Bronze (новый): 25% площадке, выплата Net-14
- Silver: 20% / Net-7
- Gold: 18% / Net-3
- Platinum: 15% / Net-1 + топ-выдача

**Статус должен приносить деньги** (скидка/быстрые выплаты), а не просто значок. Etsy Star Seller (бейдж без денег) — слабее. Сбрасывание статуса за прокол — рискованно (выжигает), лучше ступенчатые уровни.

### Приоритет 5 — Верификация и репутация (обязательно для б/у электроники)
Мелкий покупатель запчастей не может позволить себе непроверенного поставщика. Tradeloop строит на Certified Members + эскроу + комитете по спорам. Для PartsDonor: «Проверенная мастерская» + IMEI-грейдинг (как у Cellbie) + система грейдов плат A1/A2/B1/B2 (как у LCD Buyback).

### Что реально заставляет мастерскую выбрать площадку (иерархия)
1. **Доказанный спрос / покупатели** (главное) — покажи данные по трафику и waitlist покупателей.
2. Минимальное трение выкладки.
3. Прозрачные низкие комиссии, понятные выплаты.
4. Доверие/репутация (для б/у — решающее).
5. SaaS-ценность (дашборд, учёт склада, аналитика — «инструмент для бизнеса, а не доска объявлений»).

**Стратегическое предостережение:** холодный старт не решается технологией. Нужен ответ «зачем мастерской прийти до того, как там есть покупатели» — свой выкуп, SaaS-учёт их склада, гарантированный сбыт. И **запуск в узкой нише/одном городе до достижения локальной ликвидности**, а не «сразу по всей стране».

## 3. Логистика, оплата, возвраты (РФ, между мастерскими)

### Доставка
- **СДЭК — основной** (лучший API, ПВЗ-виджет, webhooks, 1-3 дня, ~180 ₽ за лёгкую посылку; корпоративный тариф от ~125 ₽ со скидкой от объёма).
- **Почта России — резервный** для малых городов/сёл (42 000+ отделений, ~120-150 ₽ за 0,5 кг, но 5-14 дней; после повышения тарифов 03.2026 лёгкие бандероли ~100 ₽).
- **Boxberry** — для компактных грузов.
- Мультиоператорность (2-3 службы) экономит **15-25%** на доставке; тарифы между операторами на одном маршруте различаются до 40%.
- Для запчастей: хрупкие (дисплеи) дорогие → добавлять страховку и упаковку явно. СДЭК «Экспресс без договора» — обязательная страховка 5000 ₽.

### Безопасная оплата / эскроу — **готовая ставка найдена**
- **ЮKassa «Безопасная сделка»** (yookassa.ru/secure-deal) — готовый продукт именно для платформ/досок: деньги замораживаются на спецсчёте до **3 месяцев**, перечисляются продавцу после подтверждения, идут споры. **Деньги не проходят через платформу.** Комиссия **от 0,4% + НДС**. Ограничение: для оборота от 800 000 ₽/мес (раньше — начать с эквайринга + холдирования).
- ЮKassa «Сплитование» — авто-деление платежа между продавцом и платформой (на старте, пока оборот мал).
- Полноценный банковский эскроу/номинальный счёт (ВТБ, Точка) — только для крупных оптовых сделок, для мелких (300-5000 ₽) нецелесообразно (ручной процесс, 3-сторонние договоры).

### Возвраты/гарантия на б/у запчасти (юридическая специфика)
- **Между ИП/ООО Закон о защите прав потребителей НЕ действует.** Работает только **ГК РФ**: продавец отвечает за **скрытые недостатки**, о которых знал и не сообщил (ст. 469, 475 ГК РФ). Возврат «передумал» закон не гарантирует — только по договору.
- Авито-подход: б/у возвращается только при скрытых недостатках или несоответствии описанию. «Как есть» (as-is) ограничивает, но не отменяет ответственность за скрытый дефект.
- **Рекомендуемые механики для PartsDonor:**
  1. Обязательное поле статуса детали: **рабочая / на запчасти / без гарантии** + фото/видео при выкладке.
  2. **Встроенное окно проверки** через безопасную сделку (заморозка до 3 мес позволяет): покупатель тестирует деталь, подтверждает, либо открывает спор.
  3. Возврат только по скрытым дефектам/несоответствию описанию (зафиксировать в оферте).
  4. **Гарантия продавца** (отраслевая практика: 7-14 дней после установки) как опция, часть суммы — гарантийный депозит через эскроу.
  5. При споре — видео-свидетельство + арбитраж/экспертиза.

### Готовые API для MVP
- **Логистика:** СДЭК REST API v2 (OAuth2, калькулятор, заказы, ПВЗ-виджет, webhooks), Почта OpenAPI (нужен ЕЛС 3-10 дней, нет webhooks), Boxberry JSON API.
- **Платежи:** ЮKassa API v3 (Безопасная сделка, Сплитование, Холдирование, чеки 54-ФЗ), CloudPayments (эквайринг НЕ эскроу).
- **Рекомендуемая связка MVP:** ЮKassa «Безопасная сделка» (расчёты с заморозкой) → СДЭК API (основная доставка) → Почта (резерв малых городов). Комиссия платформы — через сплитование или % в безопасной сделке.

## 4. Рынок и ниша в цифрах (подтверждено)

- Ремонт электроники в РФ — **~76,8 млрд ₽ (2024)**, растёт ≥10%/год. Ремонт смартфонов — **>50 млрд ₽/год**. Спрос на ремонт вырос 26-30% г/г.
- Активных мастерских/мастеров: **60-90 тыс.** (10,2 тыс. СЦ официально + >80 тыс. ИП + кустарный сектор).
- Рынок запчастей: **~15-20 млрд ₽/год**; ниша б/у и неликвида — **миллиарды ₽ замороженных на полках**.
- Практика «на разбор» — широко распространена и растёт после 2022 (дефицит оригинала → целая индустрия скупки плат/битых, разбор на живые модули).
- **Проблема подтверждена практиками СЦ:** деталь > 90 дней = dead stock; дисплеи «съедают» оборотку; склады ведутся «под столом» без учёта; совместимость живёт в голове мастера.

## 5. Итог: стратегические выводы для PartsDonor

1. **Ниша подтверждена как свободная.** Прямых конкурентов с той же моделью нет. Окно — соединить клик по схеме + донорскую деталь + историю происхождения + безопасную сделку.
2. **MVP-фит, который обязан отличить от Авито:** B2B-механики (партии, прайс-листы, отгрузки юрлицам), пересылка именно мелких запчастей, честная низкая комиссия (у Авито на дешёвой запчасти фактически 5-30% из-за минимума ~100-150 ₽ + 0 бесплатных размещений для активного продавца, 1 тариф = 1 категория).
3. **Главный барьер — не технология, а холодный старт на стороне предложения.** Решение: убить трение выкладки (фото → автоописание), бесплатная выкладка + комиссия с продажи, кнопка «продать площадке сразу», якорный оптовик/выкуп, статусы с денежной ценностью.
4. **Запуск — в узкой нише/одном городе до локальной ликвидности.** Telegram-чаты мастеров — и канал привлечения, и источник первых продавцов.
5. **Логистика/оплата готовы из коробки:** ЮKassa «Безопасная сделка» (0,4%) + СДЭК API + Почта. Возвраты — по ГК РФ (скрытые дефекты), не ЗоЗПП.
6. **Доверие = ядро:** грейдинг деталей (рабочая/на запчасти/без гарантии), верификация мастерских, фото/видео при выкладке, история происхождения от донора.

## 6. Стек / опенсорс: что переиспользовать, что писать самим

**Вердикт:** писать с нуля НЕ надо. Готовые MIT-решения закрывают инвентарь и кликабельную схему; свой дифференциатор (маркетплейс B2B + донорская карточка) пишем сами.

| Слой | Переиспользовать | Писать самим |
|---|---|---|
| Инвентарь/склад деталей | **InvenTree (MIT)** — Part, StockItem, статусы, фото, кастомные поля, BOM, REST API, плагины | — |
| UI развёртки (viewer) | **@cloudimage/hotspot (MIT)** — сцены, цена, зум, popover, multi-image | Привязка hotspot → part_id из InvenTree; слои device→схемы |
| UI редактора развёртки (админка) | **react-image-hotspot-viewer (MIT)** — add/edit/delete хотспотов | Хранение маппинга (JSON) в БД |
| Work-order / ремонтные тикеты | **Reparilo (MIT)** или на InvenTree | Если на InvenTree — тикеты/приёмка/возвраты свои |
| **B2B-маркетплейс** (каталог, цены со скидкой, корзина, заказы, мульти-мастерские, статусы «продано/в продаже») | ничего готового | **Всё своё** — это и есть основной объём |

**Почему не Part-DB (AGPL):** для коммерческого B2B-маркетплейса копилефт-лицензия тянет обязательство открывать ваш маркетплейс-слой. InvenTree (MIT) — безопасна и API зрелее.

**Уточнение по InvenTree:** статусы StockItem надо интерпретировать под «на продаже / продано» вашим слоем — из коробки этого нет.

## 7. UX по макетам (разобрано vision-моделью)

**Экран 1 — Кабинет/Склад (панель мастера):**
- Меню: Дашборд, Заказы(5), Сообщения(3), Мои объявления, Донорские устройства(8), Запчасти, **Склад(активен)**, Статистика, Отзывы, Финансы, Настройки.
- Виджеты: «Продажи за месяц 127 400 ₽», «Активных доноров 8», поиск, инфо-карточка с CTA.

**Экран 2 — Развёртка телефона (ключевой фит):**
- Табы «Разнесённый вид / Список».
- Интерактивная схема: контур телефона + выноски к плавающим карточкам (миниатюра, название, цена, зелён/красн статус).
- Зум +/-, развернуть на весь экран.
- Легенда: зелёный = в наличии, красный = продано, серый = с фото из базы.
- Ниже — сетка-список с фото, ценой, кол-вом, статусами (продано — затенено).

**Экран 3 — Карточка донора:**
- Категории: Дисплей, Материнские платы, Аккумуляторы, Камеры, Корпусные части.
- Карточка: «iPhone 13 Pro — 12 400 ₽», состояние («после падения, плата не восстановлена, компоненты оригинальные б/у»).
- Разбивка: Дисплей 4 200(✓), Плата 5 800(✓), АКБ 1 100(✓), Камера(✗продано), Корпус 1 500(✓).
- **Чекбокс «Отметить проданным»** — мастер меняет статус кликом, автосинхронизация со схемой.
- Рекомендации из других устройств, админ-бар (активных 14, модерация 2, Одобрить/Жалобы/Категории).

**UX-вывод:** трение ввода сведено к нулю — мастер выбирает модель (таб), кликает по развёртке/чекбоксам, всё остальное (описание, статусы, синхронизация) автоматизировано. Это прямое попадание в пункт «Убить трение выкладки» из ресерча.

## 8. Рекомендуемая MVP-архитектура (итог)

- **InvenTree (MIT)** — headless-инвентарь запчастей (Part/StockItem/фото/статусы/кастомные поля/BOM).
- **@cloudimage/hotspot** — вьювер развёртки; **react-image-hotspot-viewer** — редактор схемы в админке.
- **Свой B2B-маркетплейс-слой** — каталог со скидками для мастерских, корзина, заказы, мульти-мастерские, статус «на продаже/продано».
- **ЮKassa «Безопасная сделка»** (эскроу, от 0,4%) + **СДЭК API** (доставка) + Почта (резерв).
- **Frontend:** React (mobile-first), т.к. InvenTree и хотспот-библиотеки на React; одна адаптивная кодовая база (подтверждается мобильной вёрсткой макетов).
