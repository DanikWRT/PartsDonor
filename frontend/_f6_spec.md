# PartsDonor F6: отзывы/рейтинги продавца — frontend (адаптив)

Модуль frontend. Данные от B7 backend (live на http://127.0.0.1:8001, frontend dev на http://127.0.0.1:5173 через vite proxy /api → 8001).

## Acceptance (обязательно)
1. Отзывы продавца ВИДНЫ (список отзывов + средний рейтинг + количество) в карточке/кабинете.
2. Можно ОСТАВИТЬ отзыв (форма: звёзды 1..5 + комментарий) — через POST /reviews.
3. Адаптив 390px / 1440px — нет горизонтального переполнения (scrollWidth == clientWidth).
4. Скриншоты desktop + mobile (как в предыдущих F-картах: pd-fN-*.png в корне репо).

## Backend API (B7, подтверждено live)
| метод | путь | тело | ответ |
|---|---|---|---|
| POST | `/reviews` | `{rating: int 1..5, comment: str, seller_id: uuid}` | 201 ReviewOut `{id, deal_id, seller_id, rating, comment, created_at}` |
| GET | `/reviews?seller_id=<uuid>` | — | 200 `[ReviewOut,...]` отсортировано created_at desc |
| GET | `/companies/{company_id}/rating` | — | `{seller_id, avg_rating, review_count}` (avg 2 знака, 0.0 если пусто, 404 если компании нет) |
| GET | `/companies` | — | список всех компаний `CompanyOut` |
| GET | `/companies/{id}` | — | одна компания |

ReviewOut.seller_id и Company.id — это идентификаторы ПРОДАВЦА (компания). Review.rating 1..5.

## Где показать / откуда взять seller_id
- **Deal.jsx** (`/deal/:id`): есть `deal.seller_company_id` и объект `seller` (см. строки ~300-310). Это самая чистая точка, где известен seller_id. Добавь блок «Отзывы о продавце» на этот экран (можно и на /deal list, и на /deal/:id): средний рейтинг + список отзывов + форма «Оставить отзыв».
- **Cabinet.jsx** (/cabinet): есть список компаний `companies`, `companyById`. Если удобно — бонус, добавить рейтинг/отзывы в кабинет продавца по выбранной компании. Не обязательно, если Deal достаточно.
- НЕ усложняй: минимум жизнеспособный — блок отзывов на экране сделки (где seller_id гарантированно есть) ПЛЮС вывод рейтинга продавца там, где он уже отображается (PartDetail/Catalog показывают seller_rating из listing — их можно не трогать).

## Требования к UI
- Блок «Отзывы о продавце»: заголовок, звёзды+avg рейтинг (0.0→«нет отзывов»), кол-во отзывов, список (`rating` звёздами + `comment` + дата `created_at` локализованная ru-RU), форма добавления (выбор звёзд 1..5 кликом + textarea + кнопка «Оставить отзыв»).
- После POST: снова GET /reviews?+rating, обновить список и средний. Показать заметное сообщение об успехе/ошибке.
- Токен: как в Deal.jsx (`localStorage.getItem('pd-token')` → `Authorization: Bearer ...`), если нет токена — показать подсказку «нужен вход» и НЕ отправлять (или показать ошибку 401). Для чтения отзывов токен не нужен.
- Новые CSS-классы в frontend/src/styles.css (префикс `pd-`), адаптив: flex/grid переходит в 1 колонку на 390px.
- Придерживайся существующего стиля страниц (классы pd-*, useCart в Deal не ломать).

## Verify (обязательно, live)
1. `npm run build` в frontend — EXIT 0.
2. Открыть страницу сделки с известным seller_id в браузере (или через curl к /api): блок отзывов рендерится, есть вариант добавить отзыв.
3. Прогнать создание отзыва (через UI или curl) для известного seller_id → проверить, что в GET /reviews?seller_id= он появился и avg_rating пересчитан.
4. Адаптив: 390px и 1440px — scrollWidth==clientWidth в новом блоке.
5. Скриншоты сохрани в корень репо: pd-f6-reviews-desktop.png, pd-f6-reviews-mobile.png (и при необходимости детальные).
